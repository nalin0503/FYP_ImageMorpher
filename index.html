Advanced Image Morphing Pipeline

Metamorph is a state-of-the-art image morphing framework that combines diffusion-based generative models with frame interpolation techniques to create smooth, high-quality transitions between images.

This documentation provides detailed information about the parameters available in the Metamorph web application, helping you understand how to control and optimize your morphing outputs.

Main Components

Keyframe Generator

Utilizing DiffMorpher with LCM-LoRA acceleration to generate high-quality intermediate frames between source images.

FILM Interpolation
